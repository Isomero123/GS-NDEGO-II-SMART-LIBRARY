Help & Info

How do I borrow a book or material?

Fill in the borrow form and submit it. Students and Teachers see it as a request — it stays "Pending Borrow Approval" until Admin approves it. Admins log borrows instantly.

How do I return a book?

Find it in your table and tap "Return". Note the condition, whether anything is lost/damaged, and any comments, then submit — it goes to Admin as "Pending Return Approval" until confirmed. If the book is overdue, you'll also be asked to write a Letter to the Librarian explaining the delay.

Can I return a book that's borrowed under someone else's name?

No — you can only submit returns for books borrowed under your own name. If a friend's or classmate's book needs handing in, ask them to log in and return it themselves, or contact Admin.

What if my borrow or return request gets rejected?

The reason Admin gave will show right on your record so you know what to fix, and you can submit again.

Where can I see my personal borrowing history?

Your stats (Requested, Approved, Rejected, Returned, Remaining) are at the top of the Library Borrowing tab, and your table below only ever shows your own records.

Due dates

Every borrowed item has its own "Exp. Return" date, set when the borrow is logged/approved — check your record for the exact date.

Late returns

There is no automatic fine. If you return an item after its expected return date, the return form will ask you to write a Letter to the Librarian explaining the delay. Admin reviews the letter and approves or rejects it — if rejected, you'll see the reason and can resubmit.

Lost or damaged items

Same process as late returns: no automatic fine. On the return form, mark it lost/damaged (Lost, Stolen, or Damaged Beyond Repair) and write a Letter to the Librarian explaining what happened. Admin reviews the letter and approves or rejects it — if rejected, you'll see the reason and can resubmit.

Approvals

Nothing changes on the shelf or in your record until Admin reviews and confirms it — this protects everyone's stock counts and history from mistakes.

Google Sheets & Forms Sync Console

Connect and import registration records automatically

Copy rows directly from your Google Sheet or Excel file and paste them below. The system will automatically parse columns like FullName, UserClass, BookTitle, and add them instantly!

To enable real-time updates every time someone submits a Google Form, copy the Apps Script code below and paste it into your Google Sheet's Extensions > Apps Script: 

function syncToLibraryApp() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var rows = sheet.getDataRange().getValues();
  var records = [];
  
  // Start from row 2 (skipping header)
  for (var i = 1; i < rows.length; i++) {
    records.push({
      fullName: rows[i][1], // Column B
      userType: rows[i][2], // Column C
      userClass: rows[i][3], // Column D
      bookTitle: rows[i][4], // Column E
      bookKind: rows[i][5], // Column F
      isClassbook: rows[i][6] || "No",
      borrowDate: Utilities.formatDate(new Date(rows[i][7]), Session.getScriptTimeZone(), "yyyy-MM-dd"),
      expectedReturnDate: Utilities.formatDate(new Date(rows[i][8]), Session.getScriptTimeZone(), "yyyy-MM-dd"),
      status: "Active",
      bookCondition: "Good"
    });
  }
  Logger.log("Exported records: " + JSON.stringify(records));
}

Online Cloud Sync (Multi-Device / Multi-User)

Not Connected (Local Only)

This app is permanently connected to the school's shared cloud database — every device that opens it uses the same project automatically, with nothing to set up per device.

If an account "works on the phone it was created on, but not on other devices"

That almost always means the shared database's security rules aren't published (or expired — Firestore's "test mode" rules auto-expire 30 days after the project was created and silently switch to blocking everyone). Fix it in under a minute:

  1. Open the Rules tab for this project and sign in with the Google account that owns it.
  2. Delete everything in the box and paste this in:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /gsndego_app_state/{docId} {
      allow read, write: if true;
    }
  }
}

Click Publish, then reload the app on any device — the status dot above should turn to "Live — Synced Across Devices" within a few seconds.

This status also shows on the Sign In screen, so a connection problem is visible before anyone even tries to log in.
